# python-from-my-research

自分の研究コード（[shapiro-research](https://github.com/watanabe-6975/shapiro-research)：RCSJ モデルの二色シャピロステップ）を題材にした、**Python の自習教材**です。全10章の Jupyter ノートブックで、Python の基本から始めて、最後は研究報告書の計算（コヒーレント和と反実験）を自分の手でたどり直せるところまで進みます。

**例え：** ふつうの教材は「よその家の台所で料理を習う」ものですが、この教材は**自分の家の台所（研究コード）で、いつも使う材料（RK4・ステップ幅・ベッセル関数）を使って**料理を習います。習ったことが、そのまま研究コードを読む力になります。

## 使い方

```bash
pip install -r requirements.txt
jupyter lab            # notebooks/ を開いて、第1章から順に
```

全章をまとめて実行して確かめるとき：

```bash
bash tools/run_all.sh           # data/ の計算結果があれば使う
bash tools/run_all.sh --fresh   # 計算からやり直す（約1分半）
```

## この教材の約束

- **研究リポジトリには書き込まない。** 研究のコード・データは読むだけで、この教材の中で必要な部分を書き直して使っています（`kyozai/`）。
- **研究の結論を言い換えて強めない。** 第9章で報告書の計算をたどりますが、教材の計算は研究の保存データより小さい（電流は I=1.6〜4.2 だけ、A は 33 点）ので、報告書の数値と教材の数値は分けて書いています。教材で計算していないことは「未確認」と書いています。
- **図の文字は英語と記号**にしています（どの計算機でも文字化けしないように）。説明は日本語です。
